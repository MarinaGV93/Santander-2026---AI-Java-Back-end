Speech-to-Text (STT)

    A transformação. O processo de converter ondas sonoras em texto processável. Onde o áudio não estruturado ganha forma para a máquina entender.

Tool Calling

    A ponte para o domínio. A capacidade da IA de interpretar uma intenção e "chamar" funções Java específicas (Use Cases) para realizar tarefas no mundo real.

Text-to-Speech (TTS)

    A humanização. A síntese de voz. O processo de transformar a resposta da lógica de negócio de volta em uma interação humana e fluida.
